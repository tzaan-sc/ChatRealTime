================================================================================
          LỘ TRÌNH PHÁT TRIỂN & BẢN ĐỒ TÍNH NĂNG HỆ THỐNG CHAT REALTIME
                Stack: Svelte 5 + Golang + Redis + MongoDB + WebRTC
================================================================================

I. TỔNG QUAN HỆ THỐNG
--------------------------------------------------------------------------------
Hệ thống nhắn tin thời gian thực đa phương tiện (Direct 1-1, Group Chat, Audio/Video Call)
tương tự Messenger, Telegram và Discord.
Được xây dựng theo tiêu chuẩn: Gọn nhẹ, phản xạ thời gian thực mượt mà, xử lý đồng thời cực cao,
chia tách rõ ràng giữa In-Memory RAM Cache (Redis) và Cơ sở dữ liệu lưu trữ bền vững (MongoDB).


II. BẢN ĐỒ TÍNH NĂNG THEO MÔ-ĐUN
--------------------------------------------------------------------------------

[MÔ-ĐUN 1: XÁC THỰC & QUẢN LÝ NGƯỜI DÙNG (AUTHENTICATION & USER PROFILE)]
  - [x] Đăng ký tài khoản (Username, Email, Mật khẩu băm Bcrypt an toàn).
  - [x] Đăng nhập xác thực, cấp phát JSON Web Token (JWT) Access Token.
  - [x] Middleware bảo vệ REST endpoint và xác thực handshake WebSocket.
  - [x] Lấy danh sách bạn bè / người dùng trong hệ thống để nhắn tin.
  - [x] Tìm kiếm người dùng theo username/email.

[MÔ-ĐUN 2: NHẮN TIN CỐT LÕI 1-1 (CORE 1-1 REALTIME MESSAGING)]
  - [x] WebSocket Hub với kiến trúc Goroutines kép (ReadPump & WritePump).
  - [x] Redis Pub/Sub đa luồng cho từng kênh người dùng `user:{receiverId}`.
  - [x] Lưu trữ tin nhắn vĩnh viễn vào MongoDB (Collection: messages) kèm chỉ mục Index tối ưu.
  - [x] Lấy lịch sử tin nhắn của cuộc trò chuyện.
  - [x] ACK xác nhận tin nhắn gửi thành công.

[MÔ-ĐUN 3: TÍNH NĂNG REALTIME NÂNG CAO (PRESENCE, TYPING, READ RECEIPTS)]
  - [x] Heartbeat Ping/Pong định kỳ 15s giữa Client và Server.
  - [x] Quản lý trạng thái Online/Offline bằng Redis TTL (30s) và chấm xanh avatar.
  - [x] Typing Indicator: Báo "đang gõ tin nhắn..." kèm hiệu ứng 3 chấm nhảy động mượt mà.
  - [x] Đã đọc tin nhắn (Read Receipts): Tích xám 1 tích (Đã gửi) -> 2 tích xanh dương (Đã đọc).
  - [x] Âm thanh thông báo Pop nhẹ nhàng chuẩn Web Audio API khi có tin nhắn tới.

[MÔ-ĐUN 4: TIN NHẮN ĐA PHƯƠNG TIỆN (MEDIA & VOICE NOTES)]
  - [ ] Upload hình ảnh (JPG, PNG, GIF), hỗ trợ dán ảnh trực tiếp từ bộ nhớ tạm (Ctrl + V).
  - [ ] Image Lightbox Modal: Click vào ảnh trong tin nhắn để phóng to toàn màn hình sắc nét.
  - [ ] Gửi tệp đính kèm tài liệu (Word, Excel, PDF, Zip...) kèm kích thước dung lượng và nút tải về.
  - [ ] Tin nhắn thoại (Voice Note): Thu âm trực tiếp bằng Micro trên trình duyệt và phát audio player.

[MÔ-ĐUN 5: TƯƠNG TÁC TIN NHẮN (INTERACTIONS & ACTIONS)]
  - [ ] Quick Reaction Bar: Thả cảm xúc emoji nhanh (❤️, 😂, 👍, 😢, 🔥, 🚀).
  - [ ] Trả lời / Trích dẫn (Reply / Quote): Trích dẫn lại tin nhắn cũ kèm cuộn mượt tới vị trí tin gốc.
  - [ ] Thu hồi tin nhắn (Unsend / Delete for Everyone): Thay thế tin nhắn bằng thông báo đã thu hồi.
  - [ ] Chỉnh sửa tin nhắn (Edit Message): Cho phép sửa chính tả kèm nhãn `(đã sửa)`.

[MÔ-ĐUN 6: TRÒ CHUYỆN NHÓM (GROUP CHAT)]
  - [ ] Tạo phòng chat nhóm, mời bạn bè vào nhóm.
  - [ ] Phân quyền Admin / Member: Đổi tên nhóm, thêm thành viên, xóa thành viên hoặc rời nhóm.
  - [ ] Tối ưu hóa kênh Redis Pub/Sub cho nhóm: `group:chat:{groupId}` broadcast 1 lần tới tất cả thành viên.
  - [ ] Bong bóng chat nhóm hiển thị tên người gửi và avatar riêng biệt.

[MÔ-ĐUN 7: CUỘC GỌI THOẠI & VIDEO CALL REALTIME (WEBRTC)]
  - [ ] Trao đổi tín hiệu báo hiệu (Signaling: Offer, Answer, ICE Candidates) qua WebSocket Hub hiện có.
  - [ ] Kết nối P2P âm thanh và hình ảnh trực tiếp không tốn băng thông server qua Google STUN.
  - [ ] Giao diện cuộc gọi sang trọng: Màn hình chuông reo, khung Video Call Picture-in-Picture, Mute mic, Tắt camera.

[MÔ-ĐUN 8: ĐÓNG GÓI, TEST TẢI & DEPLOYMENT]
  - [ ] Multi-stage Dockerfile cho Backend Go (Binary siêu nhẹ ~15MB).
  - [ ] Multi-stage Dockerfile cho Frontend Svelte qua máy chủ web Nginx tĩnh siêu tốc.
  - [ ] File `docker-compose.yml` chạy trọn gói 4 dịch vụ (Frontend, Backend, Redis, MongoDB).
  - [ ] Kịch bản test khả năng phục hồi dữ liệu khi mất mạng đột ngột hoặc tải nặng.
